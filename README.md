# 📺 Netflix Dataset Exploratory Data Analysis

This project performs an Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to uncover trends in content distribution, ratings, release years, durations, and geographical availability. The analysis is carried out using Python and Matplotlib to derive meaningful insights through data visualization.

## ✨ Features

- Data cleaning and preprocessing
- Movies vs TV Shows distribution
- Content rating analysis
- Movie duration distribution
- Release year trend analysis
- Top 10 content-producing countries
- Year-wise comparison of Movies and TV Shows
- Data visualizations using Matplotlib

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Key Insights

- Movies dominate the Netflix catalog compared to TV Shows.
- Content production has increased significantly over the years.
- TV-MA is among the most common content ratings.
- A few countries contribute the majority of Netflix titles.
- Movie durations are concentrated within a specific runtime range.

## ⚠️ Limitation

The analysis is based solely on the provided Netflix dataset and reflects only the available records. Any changes to Netflix's catalog after the dataset was published are not represented in this analysis.
